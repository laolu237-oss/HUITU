# 2026-10-20 收藏即时生效 + 手机UI 清空显示与编辑弹窗统一

## 一句话

三条实机反馈一起修：收藏点了不保存（连带「清除非收藏」把刚收藏的也删了）、
手机UI 角色的只读弹窗和编辑弹窗长得不一样、本聊天角色找不到「添加到全局」。

## 为什么这么做

1. **收藏是列表偏好，不是条目内容**。原来「☆ 收藏」只改弹窗里的草稿变量，必须再点「完成」才写盘。
   实机会话是「点了收藏 → 看到变★ → 直接关弹窗」，结果没存；接着「清除非收藏」按「收藏 0 条」
   把整库清空。⇒ 已有条目必须**点一下立刻落盘**，新建草稿才只在保存时写入。
2. **两个弹窗的字段布局必须一致**。只读弹窗原来是自己一套 `dl/dt/dd` 排版（无框灰字），
   一看就像「另一种数据」；现在复用编辑弹窗的 `.bbi-char-form--grid` + `.bbi-char-preview`，
   只有值渲染成只读盒子。
3. **「添加到全局」藏得太深**。它原来只在编辑弹窗「更多」下拉里（还叫「提升为全局」），
   用户找过一次没找到。⇒ 提到工具条常驻按钮，并统一改叫「添加到全局」；
   手机UI 的只读弹窗也加同名按钮（= 把这条形象固化进全局库）。

## 怎么验证

```bash
node node_modules/vitest/vitest.mjs run     # 70 files / 923 passed / 3 skipped
node node_modules/vue-tsc/bin/vue-tsc.js --noEmit

```

实机：
1. 全局库随便点一条 → 点「☆ 收藏」→ **不进「完成」直接关掉** → 列表里该条带 ★，重开弹窗仍是「★ 已收藏」；
2. 「清除非收藏」的确认框此时应显示「保留 1 个收藏角色」；
3. 点手机UI 来的角色 → 弹窗排版与编辑弹窗一致（两列盒子 + 最终 tag 预览），工具条上有
   「添加到全局」「复制到本聊天」，收藏为禁用态并带说明；
4. 本聊天角色 → 编辑弹窗工具条上直接有「添加到全局」。

## 遗留 / 下一步

- 手机UI 影子条目的「收藏」仍不可用（条目不在柏宝绘存储里，收藏无处可存）。
  需要可收藏的副本就「复制到本聊天」——复制后即可收藏/删除/改。
- 收藏按钮没有二次确认（误点再点一次即取消）。

## 回滚

删掉 `toggleFavorite` 与工具条里新增的「添加到全局」按钮、把收藏按钮改回 `@click="draftFavorite = !draftFavorite"`，
只读弹窗还原成 `dl/dt/dd` 版（见 2026-10-20 上一篇的 diff），重构建即可。数据不需要回滚。
