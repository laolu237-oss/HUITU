# 2026-10-20 说明书独立成目录（无版本号变更）

## 一句话

把提示词预设的对外说明书从 `docs/PROMPT_PRESET_AUTHORING.md` 迁到仓根
`文生图转换说明书/文生图转换说明书.md`，并约定**以后只在这个目录维护**。

## 为什么

用户的实际用法是「找一本社区文生图世界书 + 说明书 → 一起丢给任意 AI → 拿回 JSON → 导入」。
说明书是要**单独外发**的东西，混在 `docs/`（还有构建脚本、预设样例）里既不好找，
也容易被连带的开发文件干扰。独立目录后，发之前只需打包这一个文件夹。

## 改了什么

- 新建 `文生图转换说明书/`，文件 `文生图转换说明书.md`（内容不变，仅迁移）。
- 文件头补「怎么用」三行（一句话指令 + 导入路径 + 同名覆盖说明），版本标注更新为 v0.3.27。
- 文件头补「维护约定」：只在此目录维护，不留副本，改动同步记入 `更新文档/`。
- 引用同步：`MAINTENANCE.md`、`更新文档/README.md`、两篇历史更新文档里的路径。
- `docs/presets/`（样例 JSON + 构建脚本）留在原处：那是开发产物，不随说明书外发。
