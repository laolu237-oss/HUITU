# 2026-10-20 只读弹窗与编辑弹窗完全对齐（含 LoRA 页签）

## 一句话

手机UI 角色的只读弹窗去掉自己那套「粉色虚线灰字」排版，改成和编辑弹窗**同一套页签、同一副字段盒子**；
并补上 LoRA 页签——说明「要挂 LoRA 复制到本聊天即可，不必添加到全局」。

## 为什么这么做

- 实机截图对比：只读弹窗用 `dl/dt/dd` + 粉色虚线底，编辑弹窗用白底实线 `BbiTextarea`，
  同一份数据看起来像两种东西；用户的原话是「这个 CSS 跟全局 CSS 要保持统一」。
- 只读弹窗原来**平铺** SFW + NSFW，而编辑弹窗是「外貌字段 / NSFW / LoRA」三个页签。
  平铺的副作用很具体：看不到 LoRA 这一档，于是「手机UI 的角色能不能绑 LoRA」这个问题无解。
- 用户的实际用法是「不一定加到全局，也会加 LoRA」——所以 LoRA 页签必须给出可执行路径：
  **复制到本聊天 → 在副本的 LoRA 页签里绑**，与全局无关。

## 改了什么

`src/pages/characters/index.vue`：

1. 新增 `phoneViewTab`（复用编辑弹窗的 `DialogTab` 类型与 `DIALOG_TABS` 定义），打开弹窗时重置为 `fields`。
2. 只读弹窗正文改为页签结构：
   - 外貌字段：SFW 两列网格 + 整串（只读盒子）+ 字段说明；
   - NSFW：页签带数量徽标（与编辑弹窗同款 `.bbi-char-tab-count`），空态给一句人话；
   - LoRA：有绑定则只读展示 文件 / 强度 / 触发词；没有绑定则给出替代路径（复制到本聊天后绑定，不必添加到全局）。
3. `.bbi-char-readonly` 重做：`padding 8px 10px` + `1px solid var(--bbi-line-strong)` +
   `var(--bbi-radius-sm)` + `var(--bbi-surface)` 底 + `var(--bbi-font-mono)`，
   与 `BbiTextarea`（`.bbi-textarea`）逐项对齐；去掉虚线粉底。
4. 最终 tag 预览保留在底部、不随页签切换；LoRA/整串模式各自打标（与编辑弹窗同口径）。
