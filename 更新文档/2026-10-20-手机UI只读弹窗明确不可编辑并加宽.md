# 2026-10-20 手机UI 只读弹窗：明确「改不了」+ 加宽

## 一句话

只读弹窗的值盒子改成**非输入框**的长相（虚线边 + 浅底 + 弱化字色），标题加「只读」徽标；
弹窗宽度从 520px 放到 680px（与编辑弹窗同宽），并修掉长整串把「最终 tag 预览」标签挤成竖排的问题。

## 为什么这么做

- 上一版为了「和编辑弹窗统一」，只读盒子做成了和输入框一模一样的外观 —— 但里面的字点不动，
  等于把一个"看着能改、其实改不了"的假输入框摆在用户面前。反馈很直接：这里应该一眼看出改不了。
- 统一的是**排版语言**（同样的两列网格、同样的字段分组与页签、同样的字号与圆角），
  不该统一的是**可编辑性**：虚线边 + 浅底是"静态值"的通用视觉，实线白底才是"输入框"。
- 520px 下两列每列只有 230px 左右，英文长串几乎一行一个词；与编辑弹窗对齐到 680px。

## 改了什么

`src/pages/characters/index.vue`：

1. `.bbi-phone-view-modal` 宽度 520px → **680px**（窄屏仍由 `@media (max-width:640px)` 收成单列）。
2. `.bbi-char-readonly` 改为：`1px dashed line-strong` + `surface-2` 底 + `ink-soft` 字色 + `cursor: default`
   （字体、字号、内边距、圆角仍与 `BbiTextarea` 一致，排版不跳）。
3. 弹窗标题加 `<span class="bbi-char-pill is-readonly">只读</span>` 徽标。
4. `.bbi-char-preview` 加 `flex-wrap: wrap`，标签 `flex: 0 0 auto; white-space: nowrap`
   —— 修掉「最终 tag 预览」被长整串挤成竖排的问题（编辑弹窗同样受益）。

## 怎么验证

```bash
node node_modules/vitest/vitest.mjs run     # 应仍全绿
node node_modules/vite/bin/vite.js build    # v0.3.34
```

实机：点手机UI 角色 → 弹窗明显变宽；字段是虚线浅底、鼠标移上去不是输入光标；
标题有「只读」；底部「最终 tag 预览」标签横排、整串在右侧换行。

## 回滚

把宽度改回 520px、`.bbi-char-readonly` 还原成实线白底、去掉标题的只读徽标与 preview 的 wrap 规则即可。
